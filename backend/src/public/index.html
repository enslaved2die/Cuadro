schedule Scheduled Refresh

Pick a time in the display's own timezone — the server automatically converts it to its own local time, regardless of where the backend is hosted (e.g. display in Colombia, server in Germany). The frame just receives "sleep for N seconds" and stays completely unaware of timezones.

When disabled, the frame refreshes on a fixed interval (DEFAULT_SLEEP_SECONDS) instead. The 24-hour panel safety watchdog still applies either way — the frame will never go longer than ~24h without a refresh even if the schedule computation is somehow off.
